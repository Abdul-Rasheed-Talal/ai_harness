# AI Harness (mypi)

A lightweight, extensible TypeScript AI Agent Harness featuring multi-provider LLM streaming and autonomous tool calling.

---

## Features

- **Multi-Provider Support**:
  - **OpenRouter** (`openrouter/free` and other models)
  - **Google Gemini** (`gemini-3.8-flash` via OpenAI compatibility)
  - **Anthropic Claude** (Native SDK or OpenAI compatibility)
  - **Groq** (`qwen/qwen3.8-27b`)
- **Autonomous Tool Calling Loop**:
  - Multi-turn execution loop that runs tools and passes results back to the LLM until task completion.
- **Built-in Agent Tools**:
  - `write`: Create and update files directly.
  - `read`: Read file contents.
  - `bash`: Execute shell commands and capture output.
  - `ls`: List files and directory structures recursively.
  - `grep`: Regex-based text search across files.
  - `stat`: Inspect file size and timestamps.
  - `find`: Search files by name pattern.

## Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Configure Environment Variables**:
   Create a `.env` file in the root directory:
   ```env
   # OpenRouter
   openrouter_api_key=your_openrouter_api_key

   # Google Gemini (or GROK_API_KEY)
   GEMINI_API_KEY=your_gemini_api_key

   # Anthropic (Optional)
   ANTHROPIC_API_KEY=your_anthropic_api_key

   # Groq (Optional)
   GROQ_API_KEY=your_groq_api_key
   ```

## Usage

### Run with Default Provider (Auto-detected from `.env`)
```bash
npm run dev -- -p "What files are in this project?"
```

### Run with OpenRouter
```bash
npm run dev -- --provider openrouter -p "Create a hello world webpage in hello.html"
```

### Run with Gemini
```bash
npm run dev -- --provider gemini -p "What is 25 * 4?"
```

### Specify a Custom Model
```bash
npm run dev -- --provider openrouter --model "meta-llama/llama-3.3-70b-instruct:free" -p "Explain recursion in 2 sentences"
```
